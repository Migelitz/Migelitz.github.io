# Personal Developer Portfolio

A personal portfolio website showcasing my software projects, technical interests, and development journey as a Computer Science undergraduate.

## Overview

This website serves as my developer portfolio, highlighting projects focused on Python automation, data processing, and software engineering.

Built from scratch using vanilla web technologies to strengthen my understanding of HTML, CSS, JavaScript, responsive design, and web fundamentals.

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)

## Features

- Responsive layout for desktop and mobile devices
- Project showcase with links to source repositories
- About and contact sections
- Downloadable resume
- Scroll-based reveal animations

1. Clone this repository.
2. Open the project using a local development server.
3. Visit the local URL provided by your development server.
