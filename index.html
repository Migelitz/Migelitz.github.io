Project notes — SortFlow +
Overview ↑ Next: AutoVal ↓

V2.0 evolved SortFlow from extension-based sorting into a deterministic heuristic classification engine. It combines filename keywords, file extensions, extracted document content, and weighted keyword signals before assigning School, Work, Personal, or an Uncategorized fallback.

Classification

The configurable 315-keyword vocabulary contains 94 School, 111 Work, and 110 Personal terms. Multi-word phrases receive weighted matches, while an extension contributes only +1. A confidence threshold prevents weak or ambiguous files from being forced into a category.

Extraction & processing

TXT, PDF, DOCX, PPTX, PNG, JPG, and JPEG content is handled through format-specific extractors using PyMuPDF, python-docx, python-pptx, and local Tesseract OCR. Heavy libraries are imported lazily only for their relevant formats.

Reliability

Watchdog events enter a thread-safe queue for worker processing. Files remain untouched until size and modification time stabilize across three one-second checks. Unstable files are abandoned after 60 seconds; dirty paths are rechecked, and collisions use atomic no-overwrite operations.
